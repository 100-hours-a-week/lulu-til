# 한 줄 정리

---

## 2026-07-20

| 개념 | 정리 |
|------|------|
| **Namespace** | 하나의 쿠버네티스 클러스터 안에서 리소스를 목적이나 팀별로 구분하여 관리하는 논리적인 공간으로, 리소스 구분, 정책 적용 단위, 명령어 범위 구분 등을 위해 사용한다. |
| **ResourceQuota** | 하나의 네임스페이스에서 요청할 수 있는 CPU, 메모리와 생성할 수 있는 쿠버네티스 리소스의 총량을 제한하는 정책으로, Namespace의 누적 요청량과 오브젝트 수를 제한하기 위해 사용한다. |
| **LimitRange** | 특정 네임스페이스에서 생성되는 개별 컨테이너나 Pod의 requests와 limits에 기본값, 최솟값, 최댓값을 적용하는 정책으로, 개별 리소스의 범위를 제한하기 위해 사용한다. |
| **Limit** | 컨테이너가 사용할 수 있는 최대한의 자원 한도이다. |
| **Request** | Pod를 실행하기 위해 쿠버네티스에게 요청하는 최소한의 자원이다. |
| **ConfigMap** | 애플리케이션이 필요한 구성 데이터를 키-값 형태로 저장하여, 이를 Pod에 동적으로 주입하거나 환경 변수로 전달하는 쿠버네티스 리소스로, 애플리케이션 코드와 실행 환경을 분리하고 설정을 중앙에서 관리하기 위해 사용한다. |
| **Secret** | 민감한 데이터를 안전하게 저장하고 Pod에 전달하기 위해 설계된 키-값 쌍 기반의 리소스이다. |
| **External Secret Operator** | 외부 비밀 관리 시스템(AWS Secrets Manager, HashiCorp Vault 등)에 저장된 민감한 데이터를 쿠버네티스 클러스터 내부로 안전하게 가져와 Secret으로 자동 동기화해 주는 오픈소스 도구로, 보안 강화와 중앙 집중식 관리, 자동 동기화 등을 위해 사용한다. |

## 2026-07-21

| 개념 | 정리 |
|------|------|
| **Controller** | 클러스터의 현재 상태를 지속적으로 모니터링하고, 사용자가 정의한 목표 상태(Desired State)와 일치하도록 조치를 취하는 자동화된 관리 루프로, 파드를 사람이 직접 관리하는 데 어려움이 있기 때문에 사용한다. |
| **ReplicaSet** | 특정 수의 Pod 복제본을 항상 유지하는 데 사용되는 컨트롤러이다. |
| **Stateless Application** | 서버가 클라이언트의 이전 요청을 기억하지 않는 방식의 애플리케이션으로, 서버 장애 시 다른 서버로 즉시 대체 가능하다. |
| **Stateful Application** | 서버가 클라이언트의 세션 상태를 기억하는 방식의 애플리케이션으로, 로그인 상태 유지 등 기능 구현이 간단하고 실시간 통신에 적합하다. |
| **Deployment** | ReplicaSet을 관리하여 Pod의 개수뿐 아니라 애플리케이션의 배포, 업데이트, 롤백까지 자동으로 관리하는 상위 Controller이다. |
| **Rollout** | 시스템이나 애플리케이션의 새로운 버전을 사용자에게 배포하는 과정이다. |
| **Revision** | 배포가 진행될 때마다 기록되는 변경 이력(또는 버전 번호)이다. |

## 2026-07-22

| 개념 | 정리 |
|------|------|
| **Networking** | 클러스터 내 Pod, 서비스, 외부 네트워크 간의 통신을 관리하고 제어하는 시스템이다. |
| **CNI** | 컨테이너 네트워크를 설정하고 관리하기 위한 표준화된 API로, 컨테이너 네트워크 설정과 관리를 표준화하여 쿠버네티스 환경에서 자동화된 네트워킹, 확장성, 유연성을 제공하기 위해 사용한다. |
| **Flannel** | 쿠버네티스를 위해 설계된 가장 단순하고 대중적인 오버레이 네트워크(Overlay Network) 플러그인이다. |
| **Calico** | 성능과 강력한 네트워크 보안 정책(Network Policy)에 초점을 맞춘 고성능 CNI이다. |
| **VXLAN** | 기존 2계층(L2) 네트워크를 3계층(L3) 네트워크 위에 가상으로 확장(Tunneling)하는 기술이다. |
| **IP in IP** | 하나의 IP 패킷 안에 또 다른 IP 패킷을 캡슐화하여 전송하는 가상화 터널링 기술이다. |
| **BGP** | 서로 다른 네트워크(Autonomous System) 간에 라우팅 정보를 교환하기 위한 핵심 인터넷 라우팅 프로토콜이다. |
