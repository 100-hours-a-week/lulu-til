# 한 줄 정리

---

## 2026-07-27

| 개념 | 정리 |
|------|------|
| **RBAC** | 사용자, 그룹, 또는 서비스 계정이 특정 리소스에 대해 수행할 수 있는 작업을 역할(Role)에 기반해 정의하고 제어하는 접근 제어 메커니즘으로, 리소스에 대한 접근을 안전하게 제어하여 보안을 강화하고 관리 체계를 체계적으로 유지하기 위해 사용한다. |
| **Role** | 네임스페이스 범위에서 특정 자원에 대한 권한을 정의한다. |
| **Binding** | Role이나 ClusterRole을 특정 사용자, 그룹, 서비스 계정에 연결하여 권한을 부여하는 리소스이다. |
| **Service Account** | Pod와 같은 애플리케이션 워크로드가 클러스터 내 리소스에 접근하거나 쿠버네티스 API와 상호작용할 수 있도록 권한을 제공하는 계정으로, 최소 권한 원칙에 따라 안전하게 인증과 권한 관리를 제공하기 위해 사용한다. |
| **Default Service Account** | ServiceAccount를 별도 지정하지 않으면 Pod가 자동으로 사용하는 기본 서비스 계정이다. |
| **User Account** | 사람이 Kubernetes 클러스터와 상호작용할 때 사용하는 계정으로, 일반적으로 인증서나 kubeconfig 파일을 사용해 인증을 수행한다. |
| **Helm** | 애플리케이션과 관련된 모든 쿠버네티스 리소스를 패키지화하고 관리할 수 있는 패키지 매니저로, 쿠버네티스 애플리케이션의 배포와 관리를 단순화하고 일관된 환경을 제공하기 위해 사용한다. |
| **Template** | 반복되는 YAML 구조를 정의하며 유지보수성을 위해 사용한다. |
| **values.yaml** | 차트에서 사용하는 기본 설정 값을 정의하며 환경별 override가 가능하다. |
| **Chart** | 차트의 이름, 버전, 설명, 차트 타입, 의존성(dependencies)을 정의하는 메타데이터 파일이다. |
| **Release** | Chart를 쿠버네티스 클러스터에 실제로 설치한 결과이다. |
| **Ingress** | 클러스터 외부의 HTTP 및 HTTPS 트래픽을 클러스터 내부의 서비스로 라우팅하는 규칙을 정의하는 리소스로, 외부에서 들어오는 트래픽을 관리하고 내부 서비스로 적절히 라우팅하기 위해 사용한다. |
| **Ingress Controller** | Ingress 리소스를 감시하고, 그 규칙에 맞게 실제 프록시나 로드 밸런서를 구성하는 컨트롤러이다. |
| **API Gateway** | 클라이언트와 여러 백엔드 서비스 사이의 단일 진입점을 제공하며, 요청 라우팅, 보안 인증, 트래픽 제어를 담당하는 소프트웨어 계층이다. |

## 2026-07-28

| 개념 | 정리 |
|------|------|
| **ArgoCD** | 쿠버네티스 클러스터의 애플리케이션 배포 및 관리를 자동화하는 GitOps 기반의 지속적 배포(Continuous Delivery) 솔루션으로, 배포를 자동화하고 운영 환경의 일관성 및 변경 이력 추적을 보장하기 위해 사용한다. |
| **선언적 관리** | '어떻게(How)' 실행할지 세부 절차를 지시하는 대신, '무엇(What)'과 원하는 최종 상태(Desired State)를 정의하여 시스템이 이를 달성하도록 맡기는 관리 방식이다. |
| **GitOps** | 애플리케이션의 배포 및 인프라 운영을 자동화하기 위해 Git을 '단일 진리의 원천(Single Source of Truth)'으로 사용하는 프레임워크로, 표준화된 협업, 안정적인 롤백, 보안 관리 등을 위해 사용한다. |
| **PLG Stack** | Promtail, Loki, Grafana의 앞글자를 딴 오픈소스 로그 수집 및 모니터링 기술 스택으로, 전통적인 ELK 스택에 비해 가볍고 자원을 적게 소비하며 쿠버네티스 및 클라우드 환경에서 로그를 효율적으로 관리하기 위해 사용한다. |
| **Prometheus** | 모니터링 및 알림을 위한 오픈소스 시스템으로, 클러스터, 파드 등의 시스템 리소스의 현재 상태를 파악하고 정보를 수집하기 위해 사용한다. |
| **Loki** | Grafana Labs에서 개발한 오픈소스 로그 집계 시스템으로, 시스템 로그 데이터를 수집, 저장, 검색하여 문제를 분석하기 위해 사용한다. |
| **Grafana** | 오픈소스 데이터 시각화 및 모니터링 도구로, 시스템 데이터를 시각화하여 현재 상태를 직관적으로 이해하고 문제를 빠르게 발견하기 위해 사용한다. |
